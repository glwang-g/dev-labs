# 能力覆盖与考核切片

本次只验证 S0 中“读懂条件分支”能力单元，不将它或九关体验路线当作 S0–S2 全阶段覆盖。

| 能力 | 训练情境 | 考核要求 |
| --- | --- | --- |
| if/else 真假路径 | 已支付与取消订单，分支产生不同值 | 两道未见数据变式全部通过 |
| 边界与组合条件 | 等于门槛、低于门槛，状态与金额联合判断 | 两道未见数据变式全部通过 |
| 多分支匹配顺序 | 多个条件成立时先匹配、跳过首分支 | 两道未见数据变式全部通过 |

训练反馈来自真实 JavaScript 执行，允许试错与提示。六种情境均完成后解锁独立考核，考核题不直接复用训练数据，统一交卷后给出能力薄弱点。任一能力点未通过则补练两个新例子，再参加新一轮考核。只有六题全部通过才记录本单元通过；这是一版可解释的保守规则，需试教校准，不作就业能力认证。

考核中平台不提供提示/AI，不逐题泄露对错；刷新恢复同一次考核与当前题，重复提交旧题不重复计分。前端状态和常规导出不包含考核答案或未来题。不能据此保证没有使用外部工具。

尚未覆盖：嵌套分支、块作用域、函数作用域、独立编写与调试、跨概念综合任务；S1、S2 完整能力矩阵和题库待后续逐单元建设。既有九关保留为体验路线，路线完成不等于阶段掌握；旧记录不迁移成能力通过记录。
