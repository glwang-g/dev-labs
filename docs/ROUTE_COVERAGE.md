# JavaScript + 订单系统：S0–S2 路线覆盖与验收

范围：一条从程序认知、语言应用到本机工程交付的路线，不代表全部 JavaScript 特性或就业认证。旧九关与条件分支样板保留，旧记录不迁移为路线通过。

| 阶段 | 能力单元 | 训练与独立考核 |
| --- | --- | --- |
| S0 | 变量/表达式、条件分支、循环控制、函数作用域、数组对象引用 | 顺序赋值、类型表达、真假/边界/匹配顺序、零次/多次/跳过/终止、参数返回值/同名局部变量、共享与复制；先训练，再换数据独立预测 |
| S1 | 聚合处理、输入校验、调试回归、测试设计 | 自己编写过滤累计与分组函数；非法数据与 TypeError；修复边界和取消订单错误；选择能暴露特定缺陷的测试 |
| S2 | 模块启动与依赖、持久化、HTTP、Git 交付 | 模块契约/运行入口/内置依赖；真实文件与新实例读取；真实 HTTP 请求；差异、提交和可运行文档 |

各训练关卡以稳定 ID 的最小 Lab 提供独立入口。能力地图的前置关系用于建议和入口诊断，不再阻止进入学习。训练覆盖不是通关。每单元的训练情境覆盖后才能独立考核；单元考核全部通过后才能参加阶段综合考核。考核中不提供提示和训练反馈，统一结束后反馈薄弱单元；未通过的单元锁为待补练，两个新任务通过后重新考核。单元与阶段结果单独保存。

S0 综合：各基础概念 + 函数/循环/分支/局部变量组合追踪。S1 综合：各能力变式 + 独立 buildReport 聚合、校验、分组与错误统计。S2 综合：完整真实回归与 Git 交付，并新增健康检查和按客户筛选接口需求，使用不同测试数据。它不只是重跑已完成练习。

训练金额范围与考核范围分开，题号和数据重新生成；题型结构仍来自已定义模板，不能据此声称测到了任意新情境。当前门槛采用全部关键检查通过，需在真实试教后校准。考核内容不经普通状态接口或学习日志导出泄露；本机文件持有人仍可读取私有存储，不能把本机版本用于高保障考试。

代码预测和函数由实际独立 Node 进程执行；工程任务使用同一真实练习仓库，新增需求后重新验收。文件编辑明确保存；函数和答案草稿按随机题号保存在本机浏览器，刷新恢复同题。切换设备不承诺恢复浏览器草稿。

延迟复测：现有路线支持重新生成独立考题，但本版尚未自动安排新路线的一周后复测；试教按 docs/PILOT.md 由教师执行并记录。数据库、生产部署、第三方依赖安装、团队协作和陌生企业仓库是后续扩展范围，不纳入当前 S2 达标宣称。

## 教师观察与补练闭环

每次新训练/考核提交保留代码或工程快照、预测/选择、真实检查、提示次数和时间。已结束考核归档保留，教师按单元查看；进行中考核的答案和结果不进入教师详情或导出。

教师可将观察关联到单元或一次已结束考核，再按上表概念指定补练。补练使用该概念现有模板的新题号与数据，不能宣称是尚未见过的结构迁移测验。达标后需现场追问才能记录教师复核完成，继续补练会创建新一轮且保留原始尝试与结论。教师结论不覆盖单元/阶段的自动考核结果。实际效果以真实体验和试教记录为依据。

## 开放 Lab 与入口诊断

既有 45 个训练位组织为独立 Lab，保持实际题型与变式范围，不新增“已掌握”的虚构能力。直接进入可选两题诊断；推荐进入也检查匹配的近期单元考核记录，不仅相信来源。诊断分为基础足够、发现缺口或跳过，均不影响探索权限，也不计为训练覆盖或独立考核通过。

可从缺口跳到桥接 Lab，再返回原现场。当前使用 90 天作为免重复诊断的记录参考期，需真实试教后校准；过期不撤销能力记录。只有一条 JavaScript 技术栈，尚未提供跨技术栈差异诊断。

普通 Lab 的题目、草稿、最近运行和诊断进度按 Lab 保存。独立考核可暂停恢复，但必须完成原有验证才能记录通过，暂停期间的作答不向教师详情和导出披露。S2 使用共享订单工程，不自动覆盖或恢复整个 Git 仓库；需要独立工程现场的 Lab 留待后续实现。

## 题目上下文与知识点

任务输入、返回值约定和公开示例属于需求说明，在训练和独立考核中均提供；不使用隐藏用例来生成说明。预测题的完整代码本身是输入，不提前展示其输出。订单函数明确 orders/records 为调用方传入的数组，逐项解释 customer、amount、status 与相应函数的校验范围。

训练时可显式打开本题知识点浮层，查阅次数和按需提示次数分别进入作答记录。浮层不写入编辑器，也不替代运行与独立验证。独立考核关闭知识点入口，服务端拒绝查阅操作；教师查看历史作答时可以回看该次提交对应的需求上下文。
